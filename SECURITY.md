# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security vulnerability within `mini-waf`, please do not open a public issue.
Instead, report findings responsibly to `security@example.com`.

Include:
- Type of vulnerability (e.g. WAF bypass, ReDoS, denial of service)
- Minimal reproducible HTTP payload or cURL command
- Impact assessment
- Proposed remediation if available

Reports will be acknowledged within 48 hours.
